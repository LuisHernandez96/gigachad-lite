## Description

Fix #8 with a root-table-only TOML scanner supporting both string quote styles, and #9 by making run/wait/result --json emit one unified result schema; update docs.

2. **#9** `cli.py`: one function `result_payload(job) -> dict` used by `run --json`, `wait --json`, `result --json`

   `stderr_path`); compute `duration_s` from timestamps when result.json is absent; null terminal fields while running.
3. Update README CLI reference ("JSON output" subsection listing the schema) and `skills/delegate/SKILL.md` (mention that
   `wait --json` returns the full result incl. extras such as Claude cost).
