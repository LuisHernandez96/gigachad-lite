## Description

Create the Python project scaffold for gigachad-lite: pyproject, package skeleton, test setup.

## Plan

1. `pyproject.toml`: build backend hatchling; `[project] name = "gigachad-lite"`, `version = "0.1.0"`,
   `requires-python = ">=3.9"`, **no dependencies**, `license = "MIT"`, description "Execute-only delegation CLI: let
   Claude Code and Codex hand work to each other". `[project.optional-dependencies] dev = ["pytest>=7", "ruff>=0.4"]`.
   `[project.scripts] gigachad-lite = "gigachad_lite.cli:main"` and `gcl = "gigachad_lite.cli:main"`.
   `[tool.hatch.build.targets.wheel] packages = ["src/gigachad_lite"]`.
   `[tool.pytest.ini_options] testpaths = ["tests"]`, `pythonpath = ["src"]`, markers `integration`.
   `[tool.ruff] target-version = "py39"`, `line-length = 110`.
2. `src/gigachad_lite/__init__.py` with `__version__ = "0.1.0"`; `src/gigachad_lite/__main__.py` that imports and calls
   `cli.main()`; `src/gigachad_lite/cli.py` with a minimal argparse `main(argv=None) -> int` supporting only `--version`
   (prints `gigachad-lite 0.1.0`), returning 0. Later tasks extend it.
3. `tests/test_scaffold.py`: `python -m gigachad_lite --version` (via `subprocess`, `sys.executable`, env PYTHONPATH=src)
   prints the version; `__version__` equals the pyproject version (parse pyproject with a regex — no tomllib on 3.9).
4. `LICENSE` (MIT, "Luis Hernandez", 2026).
