## Description

Implement the job store and the detached supervisor process to satisfy UT-A-1.

## Plan

1. `src/gigachad_lite/jobs.py`: `Job` dataclass, `JobStore` per UT-A-1. meta.json writes are atomic
   (write tmp file in same dir + `os.replace`). Liveness check via `os.kill(pid, 0)` (handle ProcessLookupError /
   PermissionError). Cancellation = create `<job_dir>/cancel` marker; if the supervisor is already dead, kill the worker
   process group directly (`os.killpg`) and mark cancelled.
2. `src/gigachad_lite/supervise.py` with `main(argv)` and `if __name__ == "__main__"`: load meta, set `running` +
   `started_at`, build the adapter command, `subprocess.Popen(argv, cwd, env, stdin=PIPE, stdout=transcript, stderr=STDOUT,
   start_new_session=True)`, write prompt to stdin and close it, record `worker_pid`, poll every 0.2s for exit / timeout /
   cancel marker. Kill = SIGTERM to the group, wait grace (`GIGACHAD_LITE_KILL_GRACE`, default 10), SIGKILL. Then
   `adapter.parse`, decide state, write result.json and final meta. Wrap everything so that an unexpected exception
   still records state `failed` with the traceback's last line as `error`.
3. POSIX only for v0.1 (process groups); on Windows raise a clear `NotImplementedError` from `start`.
4. Remove `red_phase` markers once green.
