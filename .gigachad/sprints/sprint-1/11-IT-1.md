## Description

End-to-end integration tests driving the real `bin/gcl` wrapper as a subprocess against the fake agents: full lifecycle, parallel jobs, cancel, timeout, recursion guard.

## Plan

`tests/integration/test_e2e.py`, `@pytest.mark.integration` (registered). Every call goes through
`subprocess.run([REPO_ROOT/"bin"/"gcl", ...])` with PATH = fakes dir + original PATH, `GIGACHAD_LITE_HOME` in tmp,
`GIGACHAD_LITE_KILL_GRACE=1`, and cwd = a tmp "project" dir.

1. start (codex fake, FAKE_SLEEP=1) → status shows running → wait exits 0 → result JSON has final message; logs has transcript.
2. Two parallel jobs (codex + claude fakes) started back-to-back both succeed; `status` (no id) lists both for this cwd only.
3. cancel a FAKE_SLEEP=30 job → wait exits 130; no leftover processes (check worker_pid dead).
4. `run --timeout 1` with FAKE_SLEEP=30 → exit 124.
5. Recursion: env GIGACHAD_LITE_DEPTH=1 → `start` exits 2.
6. Orchestrator shell exits: start a job from a `sh -c` that exits immediately; the job still completes (supervisor detached).
Keep total runtime < 40s.
