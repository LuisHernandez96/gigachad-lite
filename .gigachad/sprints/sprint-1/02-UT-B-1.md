## Description

Add reusable fake `codex`/`claude` executables for tests and write RED tests for the adapters module.

## Plan

Mark new test classes `@pytest.mark.red_phase` (register the marker in pyproject) and import
`gigachad_lite.adapters` lazily inside tests so collection doesn't fail.

1. `tests/fakes/codex` (python3 script, executable): reads all stdin; writes to stdout a transcript that ECHOES the
   prompt (so it contains any `TASK_COMPLETE`-like text) plus a line `codex working`; finds the value after `-o` in argv
   and writes `$FAKE_LAST_MESSAGE` (default `done`) to that file unless `FAKE_NO_LAST_MESSAGE=1`; sleeps `$FAKE_SLEEP`
   seconds (default 0); if `$FAKE_ARGS_FILE` is set, writes JSON `{"argv": sys.argv[1:], "env": {selected keys}, "stdin": ...}`
   there (keys: GIGACHAD_AGENT_CHILD, GIGACHAD_LITE_DEPTH, CLAUDECODE); exits `$FAKE_RC` (default 0).
2. `tests/fakes/claude` (python3 script): same env knobs; prints a single JSON object
   `{"type": "result", "result": <FAKE_LAST_MESSAGE>, "is_error": <FAKE_IS_ERROR == "1">, "session_id": "sess-1", "total_cost_usd": 0.01}`;
   `FAKE_BAD_JSON=1` prints non-JSON instead.
3. `tests/conftest.py` fixture `fake_agents(monkeypatch, tmp_path)` that prepends `tests/fakes` to PATH, sets
   `GIGACHAD_LITE_HOME=tmp_path/home`, and returns a helper to set FAKE_* env vars. Ensure the fakes are chmod +x in the repo.
4. `tests/test_adapters.py` — expected API (`gigachad_lite.adapters`):
   - `get_adapter("codex")` / `get_adapter("claude")`; unknown name → `ValueError` listing supported agents.
   - `adapter.build(model, mode, job_dir, extra_args, env) -> AgentCommand` dataclass with `argv: list[str]`, `env: dict[str, str]`.
     The prompt is NOT in argv (it is fed on stdin by the caller).
   - codex argv exactly: write mode `["codex","exec","-m",M,"--skip-git-repo-check","--dangerously-bypass-approvals-and-sandbox","-o",str(job_dir/"last-message.txt"), *extra, "-"]`;
     read-only mode replaces the bypass flag with `"-s","read-only"`. Aliases `luna/sol/astra` → `gpt-6-luna/gpt-6-sol/gpt-6-astra`;
     any other model passes through verbatim.
   - claude argv exactly: write `["claude","-p","--model",M,"--output-format","json","--dangerously-skip-permissions", *extra]`;
     read-only `["claude","-p","--model",M,"--output-format","json","--disallowedTools","Edit,Write,MultiEdit,NotebookEdit", *extra]`.
   - env (both): input env copied; `CLAUDECODE` removed; `GIGACHAD_AGENT_CHILD="1"`; `GIGACHAD_LITE_DEPTH` = input depth + 1 (unset → "1").
   - `adapter.parse(job_dir, stdout_text) -> ParsedResult` dataclass `final_message: str`, `is_error: bool`, `extras: dict`.
     codex: final_message = `last-message.txt` content (stripped) — even when stdout contains the echoed prompt/markers;
     missing file → `""`. claude: from stdout JSON `result`; `is_error` from JSON; extras `session_id`, `total_cost_usd`;
     bad JSON → final_message `""`, is_error True, extras `{"parse_error": ...}`.
   - One test runs the fake codex for real via `subprocess.run(cmd.argv, input=prompt, env=cmd.env)` with a prompt
     containing `TASK_COMPLETE`, then asserts `parse` returns `FAKE_LAST_MESSAGE` (not the echo).
