## Description

Document all prompt-delivery options (--prompt-file, --prompt, stdin via --prompt-file -) in the delegate skill so orchestrators under restricted permissions do not need to write a file, and release 0.1.4.

## Plan

1. `skills/delegate/SKILL.md`, section "3. Write a self-contained prompt" (and the Start command in section 4): keep the
   self-contained-prompt guidance, then add a short "Delivering the prompt" list:
   - `--prompt-file <path>` — preferred for long prompts when you can write files (keeps an audit copy).
   - `--prompt "<text>"` — when you cannot create files (e.g. your host denies file writes); quote carefully.
   - `--prompt-file -` — pipe the prompt on stdin (e.g. from a heredoc) when files can't be written and the prompt is long.
   Note that the job store always saves the prompt as `prompt.md` in the job directory, so no audit trail is lost.
2. Keep the rest of the skill unchanged; keep it host-neutral (Claude Code and Codex).
3. `tests/test_packaging.py`: assert the skill mentions `--prompt-file`, `--prompt "`, and `--prompt-file -`.
4. Version `0.1.3` → `0.1.4` in `pyproject.toml`, `src/gigachad_lite/__init__.py`, `.claude-plugin/plugin.json`,
   `.codex-plugin/plugin.json`; `CHANGELOG.md` `## 0.1.4`: "delegate skill documents --prompt / --prompt-file - for hosts that
   cannot write files (found by plugin smoke test)".
